Configuración compartida

Editor y LIVE comparten la biblioteca cuando se abren desde este mismo sitio y navegador. El canal MIDI se configura globalmente desde el engranaje de LIVE. Los datos se guardan localmente; exporta un JSON como respaldo.

Bluetooth MIDI pendiente de verificación

La entrada MIDI real necesita un navegador y sistema compatibles. Safari en iPhone no ofrece Web MIDI estándar. La GT sigue trabajando independientemente y esta beta nunca le transmite comandos.
